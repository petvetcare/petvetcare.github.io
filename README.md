# Pet Vet Care Website

A responsive static website for GitHub Pages. It introduces Pet Vet Care as a developing veterinary-services initiative for home-service inquiries and an online pet shop in Chattogram, without claiming that a physical clinic is already operating.

## Files

- `index.html` — website content and page sections
- `styles.css` — responsive layout and visual styling
- `script.js` — mobile menu, inquiry form, WhatsApp and Facebook settings
- `assets/pet-vet-care-logo.png` — logo supplied for this project

## Before publishing

1. Open `script.js`.
2. Check `whatsappNumber`. It is currently set to `8801410439495` (Bangladesh format; no `+` or spaces).
3. Replace `facebookPageUrl: "https://www.facebook.com/"` with the exact Pet Vet Care Facebook Page URL.
4. Review every service statement and ensure it reflects services you can actually provide.
5. Add genuine product photos, stock information, delivery terms, and current prices when you are ready. No competitor clinic's prices have been copied into this website.

## Publish using GitHub Pages

1. Create a GitHub repository, for example `petvetcare`.
2. Upload `index.html`, `styles.css`, `script.js`, and the complete `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the published link to appear in the Pages section.

## Important notes

- This is a static website; it does not include a database, inventory management, payment gateway, or automatic booking confirmation.
- The inquiry form opens WhatsApp with a pre-filled message. Customers must send it themselves.
- The Facebook link and WhatsApp number should be verified before publishing.
- Google Fonts require an internet connection; fallback fonts are included.
- For urgent animal emergencies, customers should seek prompt veterinary assessment rather than wait for a reply.
